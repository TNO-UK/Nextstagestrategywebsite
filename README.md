# Next Stage Strategy Website

A luxury consulting website for Next Stage Strategy, built with React, Vite, and Tailwind CSS.

## Features

- **Modern Design**: Luxury editorial design with smooth animations and interactive elements
- **Responsive**: Fully responsive across all devices
- **Interactive**: Mouse-tracking effects, scroll animations, and smooth transitions
- **Pages**: Home, Services, About, Resources, and Contact pages
- **Lead Capture**: Strategic Health Check lead magnet with form

## Tech Stack

- **React 18** - UI library
- **Vite** - Build tool and dev server
- **Tailwind CSS** - Utility-first CSS framework
- **Lucide React** - Beautiful icon library

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Open your browser and visit `http://localhost:5173`

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build locally

Build the production-ready files:

```bash

```

The built files will be in the `dist` directory, ready to deploy to any static hosting service (Netlify, Vercel, GitHub Pages, etc.).
